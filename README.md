# Customer Behaviour Analysis - Data Analyst Project

## Project Overview
This project focuses on analyzing customer shopping behavior using Python, SQL Server, and Power BI to uncover business insights that help improve revenue, customer retention, and marketing strategies.

The project includes:
- Data Cleaning & Preprocessing using Python
- Exploratory Data Analysis (EDA)
- SQL-based Business Analysis
- Interactive Power BI Dashboard
- Customer Segmentation & Revenue Analysis

---

# Tech Stack

- **Python** – Pandas, NumPy, Matplotlib, Seaborn
- **SQL Server** – Data querying and business analysis
- **Power BI** – Dashboard creation and visualization
- **Jupyter Notebook** – Data analysis workflow

---

# Dataset Information

### Dataset Type
Retail / E-commerce Dataset

# Business Problems Solved

# Project Workflow

## 1. Data Cleaning & Preprocessing
- Handled missing values
- Corrected category inconsistencies
- Removed duplicate records
- Standardized column names
- Exported cleaned dataset to SQL Server

## 2. Exploratory Data Analysis (EDA)
Performed analysis on:
- Customer demographics
- Revenue trends
- Product category performance
- Discount usage patterns
- Purchase frequency
- Customer ratings

## 3. SQL Analysis
Business queries performed:
- Highest revenue-generating category
- Impact of discounts on purchases
- Top-rated products
- Revenue contribution by age group
- Customer segmentation analysis
- Subscription vs non-subscription spending

## 4. Power BI Dashboard
Created an interactive dashboard containing:
- KPI Cards
- Revenue Analysis
- Customer Insights
- Product Performance
- Seasonal Trends
- Customer Segmentation

---

# Key Insights

- Certain product categories generated significantly higher revenue.
- Repeat customers contributed major revenue share.
- Discounts increased purchase engagement.
- Subscribers showed higher average spending.
- Seasonal trends impacted purchasing behavior.
